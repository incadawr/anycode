AnyCode

Одно рабочее пространство поверх нескольких AI-агентов

0.0.8 · alpha

Оболочка, а не агент

AnyCode — единое десктопное рабочее пространство поверх уже установленных AI-кодовых агентов: Claude Code CLI, Codex CLI или собственного мульти-провайдерного агент-цикла. Воркспейс одинаковый для любого движка.

Bring your own agent: профиль запускает ваш CLI под вашей учёткой и на условиях вашего провайдера. AnyCode не хранит и не проксирует креды — процесс работает на вашей машине.

Три профиля движков

Claude Code

Официальный CLI в headless-стриме: вложения-изображения, reasoning effort, индикатор контекста, режимы разрешений.

Codex

OpenAI Codex CLI по протоколу app-server: профили аккаунтов, квоты и панель плана, импорт сессий, управляемый бинарник.

Native

Собственный цикл: Anthropic, Z.AI/GLM, OpenAI, OpenRouter, DeepSeek, Moonshot, Kimi — и любые OpenAI-/Anthropic-совместимые эндпоинты, включая локальные.

Саб-агенты и надёжность

Кросс-движковые саб-агенты

Саб-агенты не привязаны к движку сессии: профиль .anycode/agents/*.md может указать engine: codex или engine: claude — дочерний агент пойдёт как настоящий процесс соответствующего CLI.

Недоступный движок — громкая ошибка, а не тихий фолбэк.

Протокольные фикстуры

Оба CLI-профиля закреплены фикстурами: адаптер, теряющий или выдумывающий сообщение, роняет сборку. Сверка пина со свежим CLI — отдельный opt-in прогон.

Возможности следуют движку: то, что бэкенд не умеет, отключено, а не имитировано.

Статус и старт

0.0.8 · alpha. Хранилище, API и UI могут меняться без обратной совместимости; сборки не подписаны (подпись — с бетой).
