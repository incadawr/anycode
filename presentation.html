AnyCode

One desktop workspace over several AI coding agents.
Not another agent — the shell around the agents you already run.

Transcript, tool calls, permission prompts, file actions, terminal, context usage, MCP servers, skills, subagents and Git review — the same workspace, whichever engine runs the session.

01The idea

  • Bring your own agent. A profile launches an agent CLI you already installed — under your account, on your machine. AnyCode never stores or proxies credentials.
  • One UI, interchangeable engine. The shell consumes an event stream and doesn't care which engine produced it.
  • Capabilities follow the engine. Each profile exposes what its backend supports; impossible actions are disabled, not faked.
  • Subagents pick their own engine. A Native session can hand a task to the Codex or Claude Code CLI and get the result in the same transcript.

03Built on verifiable ground

  • Protocol fixtures pin both CLI profiles. Adapters must stay in sync with recorded wire streams — a dropped or invented message fails the build, not your session.
  • Live re-checks are opt-in. Pinning against a freshly released CLI is a separate run against the real binary.
  • Honest validation status. Codex and Claude Code profiles: fixtures + live smoke. Native: end-to-end proven on Z.AI (GLM) and Kimi; other providers configured but less exercised.

04Where it's heading

anyPlugin

Public plugin ecosystem: manifest spec, install from git/archive, management UI, more contribution types.

MCP, first-class

Management surface for MCP servers: status, tool lists, toggles, remote servers with OAuth, on-demand tool loading.

Mid-session switching

Change model, provider — or the whole engine — between turns, with explicit capability and cache-cost surfacing.

Multi-agent orchestration

A supervisor session that plans, spawns role-scoped agents, and reviews results — substrate for deep-research mode.

Universal preview

Markdown, diffs, images and live dev-server pages rendered next to the chat; agent-facing screenshot/console loop on top.

Checkpoints & plan mode

Per-turn workspace snapshots with rollback, and a read-only planning phase producing an approvable plan.

06Try it

Installers for macOS, Windows and Linux are on the GitHub Releases page — or run from source (Node 22+, pnpm 10):

# from source
pnpm install --frozen-lockfile
pnpm --filter @anycode/desktop dev

# verify
pnpm -w typecheck && pnpm test
