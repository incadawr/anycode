AnyCode

One workspace on top of several AI coding agents

0.0.8 · alpha

A workspace, not an agent

AnyCode is one desktop workspace on top of the AI coding agents you already have: Claude Code CLI, Codex CLI, or its own multi-provider agent loop. The workspace is the same for every engine.

Bring your own agent: a profile runs your CLI under your account and your provider's terms. AnyCode does not store or proxy credentials — the process runs on your machine.

Three engine profiles

Claude Code

The official CLI in headless streaming mode: image attachments, reasoning effort, context meter, permission modes.

Codex

OpenAI Codex CLI over the app-server protocol: account profiles, quotas and plan panel, session import, managed binary.

Native

Its own loop: Anthropic, Z.AI/GLM, OpenAI, OpenRouter, DeepSeek, Moonshot, Kimi — and any OpenAI- or Anthropic-compatible endpoint, including local ones.

Subagents and reliability

Cross-engine subagents

Subagents are not tied to the session engine: a .anycode/agents/*.md profile can set engine: codex or engine: claude, and the child runs as a real process of that CLI.

An unavailable engine is a loud error, not a silent fallback.

Protocol fixtures

Both CLI profiles are pinned by recorded fixtures: an adapter that drops or invents a message fails the build. Checking the pin against a new CLI is a separate opt-in run.

Features follow the engine: what the backend cannot do is disabled, not imitated.
